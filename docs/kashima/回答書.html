一般介護予防事業（地区巡回型介護予防検診）委託事業　／　独自システム（クラウド環境）の利用について

平素より大変お世話になっております。標記委託事業の遂行にあたり利用しております当社システム 「Cruto motion」について、貴町よりご照会をいただきました安全管理措置の確認事項に対し、下記のとおり回答いたします。

１．システム利用の概要（操作主体およびデータ保存場所）

(1) 操作主体

本システムにおける個人情報の入力・閲覧・加工・出力等のすべての業務操作は、 当社の従事者のみが行います。クラウド事業者（Google）を含む第三者が業務データを操作することはありません。 また、再委託先・外部業者等にアカウントを付与することはありません（契約上の再委託禁止規定を遵守しております）。

(2) データの保存場所

個人情報を含むデータは、Google Cloud／Firebase の東京リージョン（asia-northeast1）に限定して保存しており、 国外のデータセンターに保存することはありません。システム構成とデータの流れは図１のとおりです。

２．利用しているクラウドサービスの安全性（ISMAP 登録状況）

本システムの基盤として利用している Google Cloud Platform および Firebase は、いずれも ISMAP（政府情報システムのためのセキュリティ評価制度）のクラウドサービスリストに登録済みです。

３．委託期間完了後のデータ完全消去について（誓約）

(1) 誓約事項

「委託期間終了後、データを当庁に返却した後は、クラウド上を含め全ての個人情報を完全に消去し、 後日消去報告書を提出する」ことを誓約いたします。

すなわち、仕様書に基づき委託期間終了後に個人情報データを貴町へ返却（納品）したのち、 当社が管理するシステムおよびクラウド上（バックアップ環境を含む）に保存された本業務に係る個人情報のすべてを、 復元不可能な状態で完全に消去いたします。消去完了後は、速やかに消去報告書を貴町へ提出いたします。

(2) 消去の対象

本業務に係る個人情報について、以下のすべてを消去の対象とします。運用上の控え（削除済みデータの退避領域）や 読み取り処理の中間データも漏れなく対象に含めます。

(3) 消去の時期

  • 個人情報データを貴町へ返却し、受領のご確認をいただいた日から 30 日以内に消去を実施します。
  • 消去完了後10 日以内に、消去報告書を貴町へ提出します。
  • 貴町よりご指定の期日がある場合は、そのご指示に従います。

(4) 消去報告書の記載事項

  • 委託業務名・委託期間
  • 消去を実施した年月日
  • 消去した個人情報の種類・件数（表２の区分による）
  • 消去の方法
  • 消去実施者および確認者の氏名
  • 当社代表者による証明（記名押印）

４．第三者がデータに触れないことの担保

第三者が本システムのデータに触れないことを、次の技術的・組織的措置により担保しています。

  • アカウントの限定：システムにログインできるのは当社の従事者のみです。ログインは ID（メールアドレス）・パスワード認証によります。
  • 管理者による許可制：ログインできただけではデータを閲覧できません。管理者が職員として登録した利用者のみが、システムのデータにアクセスできる設定としています（サーバ側のセキュリティルールにより強制）。
  • 再委託の不実施：再委託先・外部業者等の第三者にアカウントを付与することはありません。
  • クラウド事業者の従業員による閲覧の排除：Google Cloud の利用規約・データ処理条項において、顧客データへのアクセスは厳格に制限されています。Google の従業員が本業務のデータを閲覧・加工することはありません。
  • 通信・保存時の暗号化：端末とクラウド間の通信はすべて HTTPS（TLS）で暗号化され、保存データは Google Cloud の既定により暗号化されています。
  • 削除済みデータの隔離：誤削除に備えた控えは、当社職員からも画面上一切閲覧できない設定としており、書き換え・消去もできません（消去は本書「３」の手順により管理者が実施します）。
  • 操作記録の保全：削除等の重要操作については、実施者・日時・対象の記録を残しています。
